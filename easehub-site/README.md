# Easehub Site (offline)

Open `index.html` in any browser. No internet connection is needed.

- `index.html`: landing page (hyperspace hero, search, dark mode, login, menu)
- `services.html`, `products.html`, `contact.html`: separate pages
- `portal/index.html`: student and admin dashboard

Demo accounts (portal):
- Admin: admin@easehub.example / admin123
- Student: student@easehub.example / student123

The contact page's WhatsApp button opens WhatsApp only when you are online.
