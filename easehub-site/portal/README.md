# Easehub Portal

Shared login for students and administrators, with a student dashboard
(coins, rewards, redeemed history, booked orders, feedback, profile) and an
admin dashboard (add coins, process reward orders).

## Files
- `index.html`: page structure
- `css/style.css`: all styles
- `js/app.js`: all behaviour (login, dashboards, data stored in the browser)

## Run it
Open `index.html` in a browser. No install or server is needed.

## Demo accounts
- Admin: admin@easehub.example / admin123
- Student: student@easehub.example / student123

## Before going live
Data and passwords live in the browser and are visible in the code. Add a
backend with hashed passwords and a database before real use.
